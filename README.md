# Go Exercises

![Go](https://img.shields.io/badge/Go-00ADD8?logo=go&logoColor=white)

Small Go programs written to practise the language, inspired by [Gophercises](https://gophercises.com).

| # | Exercise | Concepts |
|---|---|---|
| 1 | **Quiz** — timed quiz read from a CSV file | `encoding/csv`, `flag`, goroutines, channels, `time.Timer` |

```bash
cd "1. Quiz" && go run main.go -csv problems.csv -limit 30
```
